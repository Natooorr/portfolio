# Portfolio

Personal portfolio website for Zachris Stenhammar.

- **Live Site (EN):** [natooorr.github.io/portfolio](https://natooorr.github.io/portfolio/)
- **Live Site (SV):** [natooorr.github.io/portfolio/sv.html](https://natooorr.github.io/portfolio/sv.html)

## Overview

Built as a lightweight, zero-dependency static site hosted on GitHub Pages.

- Vanilla HTML5, CSS3, and JavaScript
- Dark / Light mode toggle with local storage persistence
- Bilingual support (English & Swedish)
- Mobile-responsive layout

## Local Preview

Start the built-in development server:

```bash
node server.js
```

Then visit `http://localhost:3000`.
